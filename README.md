# GreenDB MVP

첨부된 IRB 계획서만을 바탕으로 새로 만든 로컬 웹앱입니다. 기존 작업 폴더의 ESG 파일은 사용하지 않습니다.

## 실행

Windows에서 `start.bat`를 더블클릭하거나 Python 3.10 이상으로 실행합니다.

```powershell
python server.py 8765
```

브라우저에서 <http://127.0.0.1:8765>를 엽니다. 외부 패키지 설치는 필요하지 않습니다. 데이터와 업로드 원본은 `data/`에 저장됩니다.

## 구현된 흐름

1. 기업활동 10개 질문에 답하고 환경영역을 추천받습니다.
2. 추천 영역을 직접 추가·제외하고, 사업장과 관리 범위를 등록합니다.
3. 선택한 영역의 기본 데이터 항목을 사용하거나 항목을 직접 만듭니다.
4. PDF, Excel, CSV, 텍스트, 이미지를 업로드하고 원본을 보관합니다.
5. 문서의 값·단위·날짜 후보를 확인하고 사업장·기간·증빙과 함께 저장합니다.
6. 항목명 중심으로 기록을 검색·필터링하고, 누락 항목과 연도별 축적 현황을 봅니다.
7. CSV 또는 JSON으로 내보냅니다.

## 범위와 한계

- 계획서에 언급된 119개 변수의 원본 DB는 첨부 PDF에 포함되지 않았습니다. 앱에는 계획서의 관리영역에 맞춘 37개 시작 항목을 넣었으며, 사용자 정의 항목을 추가할 수 있습니다.
- PDF·Excel·텍스트는 로컬 규칙으로 수치 후보를 제시합니다. PDF 텍스트 추출에는 `pdftotext`가 필요합니다. 이 컴퓨터에서는 Git 설치본의 `pdftotext`를 자동 탐지합니다.
- 이미지 OCR은 `tesseract`가 설치되어 있을 때 사용합니다. 스캔 PDF와 이미지의 추출이 안 되는 경우 원본을 보며 직접 입력할 수 있습니다.
- 자동 추출 결과는 확정하지 않습니다. 사용자가 값·단위·기간·사업장을 검토하고 저장해야 기록으로 반영됩니다.
- 이 앱은 한 컴퓨터에서 한 기업이 사용하는 로컬 MVP입니다. 계정·권한·클라우드 동기화·ESG 산정·공식 평가 기능은 포함하지 않습니다.

## 데이터 보호

서버는 `127.0.0.1`에만 연결됩니다. `data/`에 올린 원본 파일과 SQLite 데이터베이스가 함께 보관되므로 주기적으로 폴더를 백업하세요. JSON 내보내기에는 원본 파일 자체가 포함되지 않습니다.

## Vercel 배포본

`build_vercel.py`를 실행하면 `public/`에 정적 배포본이 생성됩니다. 배포 설정은 `vercel.json`에 있습니다. `vercel deploy`로 미리보기, `vercel deploy --prod`로 운영 주소에 배포할 수 있습니다.

배포본은 로그인 기능이 없는 공개 데모이므로 기업 정보와 원본 파일을 각 방문자의 브라우저 저장소에만 보관합니다. 다른 기기와 동기화되지 않고 브라우저 데이터를 지우면 기록과 파일이 사라집니다. CSV와 JSON 내보내기로 기록을 백업할 수 있지만, JSON에는 업로드 원본 파일이 포함되지 않습니다. PDF 텍스트 추출에는 함께 배포한 PDF.js를 사용합니다. 공식 서비스로 사용하려면 로그인, 접근 제어, 지속 저장소와 백업을 추가해야 합니다.
